## Objective

Attempt to falsify the evidence supporting the Ada-RCA V1 scientific method.
This audit may close the evidence only if frozen prediction provenance,
independently reconstructed metrics, paired-bootstrap statistics, and the
predictive-path leakage audit survive. It does not authorize method selection,
new training, new features, new hyperparameters, or optimization.

## Immutable inputs

The `research/performance-optimization` branch and its artifacts are an
immutable experiment record. Existing prediction, score, ranking, and root-rank
files are frozen inputs. Missing prediction evidence must not be regenerated by
fitting a model, even with the same seed. Every frozen input used by this audit
must be recorded with a SHA-256 digest.

## Gate order

1. **Gate 0 — Frozen Evidence Inventory.** Establish exact case, fold,
   candidate, root, score, and ranking coverage for V1-SCIENTIFIC, GLOBAL-OPT,
   and PER-DATASET-OPT.
2. **Gate 1 — Independent Metric Reconstruction.** Derive root ranks from
   complete frozen rankings when available, otherwise use an explicitly
   identified immutable root-rank artifact. Recompute AC@1, AC@3, AC@5,
   Avg@5, and MRR without importing the legacy evaluator or its aggregate
   summary.
3. **Gate 2 — Bootstrap Forensic Audit.** Only after Gates 0 and 1 pass,
   audit the legacy result and compute `Candidate - V1` with paired,
   fault-stratified case resampling (10,000 iterations, seed 20260829).
4. **Gate 3 — Telemetry Information-Loss Audit.** Quantify only stages that
   can be supported using candidate-case pairs. Undefined or unavailable
   stages remain explicit; no sparse feature is admitted.
5. **Gate 4 — Provenance and Claim Normalization.** Preserve legacy artifacts
   while correcting active terminology, ranker execution semantics, and claim
   strength.
6. **Gate 5 — Scientific Decision.** Select exactly one allowed terminal
   state from the evidence, without modifying the method.

## Mandatory stop conditions

Stop dependent downstream scientific work when any of the following occurs:

- candidate registry, root mapping, case coverage, or ranking integrity fails;
- a required frozen result cannot be recovered without model fitting;
- reconstructed metrics disagree beyond an explicit numeric tolerance;
- explicit root/fault labels enter the predictive feature path;
- bootstrap pairing is fundamentally invalid and cannot be repaired from
  frozen case-level evidence; or
- any operation would alter existing predictions or the frozen search space.

The last condition emits:
`SCIENTIFIC_METHOD_CHANGE_REQUIRED — STOPPED FOR HUMAN REVIEW`.

## Statistical contract

The bootstrap sampling unit is the failure case, never a candidate row. Within
each fault stratum, each iteration samples with replacement exactly the
original number of cases. Both methods use the identical sampled case IDs.
Required executable invariants are identity, antisymmetry, direct-point
consistency, pairing, stratum-size accounting, and seed reproducibility.

The interval is a percentile interval of paired case-level metric differences.
It is conditional on the fixed predictions and does not include uncertainty
from dataset reuse, model/search selection, or system sampling.

## Claim boundary

Passing a label-firewall test supports only
`NO_EXPLICIT_LABEL_LEAKAGE_DETECTED`; it does not prove absence of service or
telemetry fingerprints. Historical recovered results are not canonical
replays or unbiased comparators. Unavailable XGBoost and LightGBM families are
`NOT EXECUTED — DEPENDENCY UNAVAILABLE`. Optimization conclusions are limited
to the actually executed search space.

Only a passing or limitation-qualified freeze may produce final-freeze and
thesis-results documents. Historical metrics and prediction artifacts are
never rewritten.
